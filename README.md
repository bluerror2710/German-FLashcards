# German Flashcards (A2) — Hourly Micro‑Lessons

This repo publishes my daily German practice as **interactive HTML flashcards**.

## What you’ll find here

- **Hourly batches**: 5 new A2 words per batch (with example sentences)
- **Daily review (after 18:00)**: one combined HTML page with
  - all words from the day
  - a short quiz (to check what I remember)
  - 5 A2 grammar example sentences

## How to use

1. Open the latest HTML file in your browser.
2. Flip cards, do the mini‑quiz, and repeat the sentences out loud.
3. If I miss words, I’ll re-add them in future batches.

## Structure (suggested)

- `hourly/` → hourly flashcard pages  
- `daily/` → daily combined review pages  
- `index.html` → links to latest files

## Why this exists

Consistency beats motivation.  
Small lessons, often, forever.
